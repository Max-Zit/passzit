Installing the server

PassZit is one program, passzit-server, with a PostgreSQL database. Packages for Debian/Ubuntu and RHEL, a one-line installer and ready appliance images follow with version 0.5; until then the server is built from source.

Requirements

  • Linux (Debian 12, Ubuntu 22.04/24.04, RHEL 9 or compatible), 1 CPU, 1 GB RAM, a few GB of disk.
  • PostgreSQL 14 or newer.
  • A name and a certificate the browsers trust — browser extensions refuse self-signed certificates. Built-in Let's Encrypt support follows later.

Building from source

git clone https://github.com/Max-Zit/passzit
cd passzit
go run ./tools/buildwasm          # Argon2id for the browser
go build -o passzit-server ./cmd/passzit-server

Running

export PASSZIT_DB=postgres://passzit:SECRET@localhost/passzit
./passzit-server --data-dir /var/lib/passzit --listen :8443

On the first start the server creates its secret key (secret.key), a certificate and a setup token (setup-token.txt) in the data directory. Open https://SERVER:8443, enter the token and create the first administrator.

Back up the database and secret.key. The vaults are encrypted by the users' keys, but the server's own secrets (second factors, session keys) need secret.key.

Command-line options

OptionMeaning
--data-dircertificates, secret key, logs (default /var/lib/passzit)
--dbPostgreSQL URL (or PASSZIT_DB)
--listenaddress and port, overriding the saved setting
--reset-allowlistallow the private networks again and exit
--unblock-iprelease a blocked address (or all) and exit
--dev-embedded-dba private PostgreSQL in the data directory — for tests and demos only
--dev-no-2fasign in without the second factor — test and demo servers only, needs --dev-embedded-db; every page shows a warning
