Working with the vault

The vault holds your logins, secure notes, cards, identities and SSH keys. It opens after the sign-in, and again with the master password after it locked.

Items

  • Login — name, user name, password, one or more websites, notes and own fields.
  • Secure note — a name and text, for licence keys, Wi-Fi passwords, PINs and the like.
  • Card — cardholder, number, expiry and security code. The number is shown with its brand and hidden until you click the eye.
  • Identity — name, address, e-mail, phone and company, for forms you fill in again and again.
  • SSH key — a private and public key with an optional passphrase. Generate an Ed25519 key makes a new key in the browser; paste the public key into ~/.ssh/authorized_keys on a server.

Click New item and choose what you save: a website login, a device you open with Remote Desktop (RDP), SSH or WinBox, an SSH key, a secure note, a card or an identity. Fill in the fields and Save. For a device the address comes first; without a name the item is named after the address. The dice button next to the password opens the generator; Use this password puts the result into the item. More fields adds own fields — mark them Hidden for secrets.

In the item view, the copy buttons copy the user name or password; copied passwords disappear from the clipboard again after the time in your account settings. The eye shows a hidden value. Websites open in a new tab.

One-time codes (two-factor sign-in)

A login can hold the Authenticator key (TOTP) a website shows when you switch on its two-factor sign-in — paste the secret key or the whole otpauth:// address. When the website shows only a QR code, click the QR button next to the field and choose a picture or screenshot of it, or paste a copied picture into the field; the QR code is read in your browser. The item then shows the current six-digit code with the seconds it is still valid, ready to copy. Keep in mind: whoever opens the vault then has both factors; for the most important accounts a separate authenticator app keeps them apart.

Attached files

Attach a file in the item view adds files such as key files, certificates or scans. Each file is encrypted in the browser with its own key, which is kept inside the encrypted item — the server stores only bytes it cannot read. The administrator sets the largest file (10 MB) and the storage per user (500 MB). Download decrypts a file in the browser; deleting the item forever deletes its files too.

Password health

Password health under Tools lists logins with weak passwords, passwords reused on several websites and passwords not changed for a year, with a score of how many logins are fine. The check runs completely in the browser.

If the administrator switched it on, Known data breaches checks your passwords against the Have I Been Pwned list of leaked passwords. Only the first five characters of each password's SHA-1 hash are sent; the answer contains hundreds of hashes and the match is found in the browser, so neither PassZit's server nor the service learns a password.

Password history

When you change the password of a login, the old one is kept in the item's Password history (the last ten), encrypted like everything else. The item shows when the password was last changed.

What a vault holds

Open My vault or a team vault on the left. Above the list a row shows what the vault holds — Websites, Credentials (logins without a website), RDP, SSH, WinBox, SSH keys, Secure notes, Cards, Identities and Favorites, each with its count; a click shows only that kind, a second click all again. Every item has the icon of its kind: a globe for websites, a card for credentials, a screen for RDP, a terminal for SSH, a router for WinBox. With a kind chosen, New item starts with that kind.

Folders, favourites, search

  • Folders belong to a vault, and everyone with access to a team vault sees its folders — for example one folder per customer, with a folder per site inside. The folder button next to the vault name makes a folder; the buttons on a folder make a folder inside it, rename or delete it. Click a folder to open or close it; new items go into the folder you clicked last, and the item editor can move an item to another folder. Deleting a folder moves what it holds one level up.
  • Favourites: the star in the item view. Favorites above the list shows them.
  • Search looks through names, user names, websites, addresses and notes of the open vault — in your browser, because only it can read them. The button in the search field searches all your vaults; each result shows its vault and folder.

Trash

Move to the trash hides an item; in the Trash it can be restored or deleted forever. Items in the trash are deleted automatically after the number of days of the policy (30 by default).

Several devices and tabs

The vault looks for changes every 30 seconds and loads them. If an item was changed on another device while you edited it, saving is refused with a message: reload and make your change again — nothing is overwritten silently.

Password generator

Password makes random characters (length 8–64, with or without capitals, digits and symbols; similar-looking characters like l, 1, I, O and 0 are left out unless you want them). Passphrase joins random words from a list of 7 776 words — five words give about 65 bits and are much easier to type. The strength shown is the real randomness of the result.
