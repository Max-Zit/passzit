Import and export

Moving to PassZit or taking your data elsewhere: files are read and written in your browser. The server only ever receives the items encrypted.

Importing

  1. Export your passwords from the old program (see below).
  2. In the vault choose Tools → Import and pick the file. PassZit recognises the format and shows how many items and folders it found, and how many are already in your vault.
  3. Choose whether to keep the folders of the file or to put everything into a new folder, and whether to skip items that are already in the vault. Then Import.
  4. Delete the export file of the old program — it holds your passwords unencrypted.

Logins, secure notes, websites, own fields, folders (also nested folders of KeePass), favourites and TOTP secrets are taken over. Cards, identities and attachments come with a later version.

Exporting

Tools → Export asks for your master password and offers two formats:

  • Encrypted PassZit file (recommended) — protected with a password you choose (Argon2id and AES-256-GCM, like the vault). Use it as a backup copy of your own; it can be imported into PassZit again. Without its password the file cannot be opened.
  • CSV, unencrypted — for moving to another program. Anyone who gets this file can read every password: delete it right after the move.

Imports and exports are recorded in the audit log (the number of items, never their contents); an unencrypted export is marked as such.
