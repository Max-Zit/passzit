Browser extension

The PassZit extension fills your logins into websites, offers to save new ones and makes passwords — in Chrome, Edge, Opera, Brave, Vivaldi and Firefox. It brings its own code, so the server cannot change what runs in your browser.

Installing

  • Chrome, Edge, Opera, Brave, Vivaldi: the Chromium package passzit-extension-chromium-VERSION.zip. Until it is in the stores: unzip it, open chrome://extensions (edge://extensions, opera://extensions …), switch on Developer mode and choose Load unpacked.
  • Firefox: the Firefox package passzit-extension-firefox-VERSION.zip (Firefox 128 or newer). Firefox installs only signed add-ons permanently; until the add-on is published, load it for testing in about:debugging → This Firefox → Load Temporary Add-on.

Signing in

  1. Click the PassZit icon and enter the address of your server (for example https://vault.example.com), your e-mail address and the master password.
  2. The browser asks once whether PassZit may talk to that server — allow it.
  3. Enter the code of your authenticator app. Two-factor sign-in must already be set up in the web vault.

The extension appears under My account → Active sessions with the name of the browser; you can sign it out there. It stays signed in for 30 days (set by the administrator) and is signed out earlier when it is not used for 14 days.

The server needs a certificate the browser trusts. With the self-signed certificate of a fresh server the extension cannot connect — use your own certificate or a name with Let's Encrypt.

Filling logins

  • Open the sign-in page, click the PassZit icon: This site lists the logins for the website. Fill puts user name and password into the page.
  • Keyboard: Ctrl+Shift+L fills the login directly when there is exactly one for the site, otherwise it opens the list.
  • The copy buttons copy the user name or the password; copied passwords are cleared from the clipboard again.

PassZit offers a login only on its own website: shop.example.co.uk gets the logins of example.co.uk, but a login for one github.io page is never offered on another, and a login saved for HTTPS is not offered on plain HTTP. It fills only visible fields of the top page, never into frames of other sites, and checks again right before filling that the page has not changed.

Offering to save

In the menu (≡) switch on Offer to save new and changed logins. The browser then asks for access to all websites — needed to notice when you sign in or change a password. When you do, the PassZit icon shows a number; open it and choose Save or Update. PassZit never shows anything inside the web page itself, so a page cannot imitate or click the offer.

Locking

The extension locks after the same inactivity time as the web vault and when the browser closes; the lock button locks at once. Unlocking needs only the master password. The keys are kept in the browser's memory, never on disk.

Generator and search

Generator makes passwords and passphrases like the one in the web vault; Search finds any item of your vault to copy its user name or password.

Remote connections

With the PassZit helper the extension also opens RDP, SSH and WinBox connections of your logins — see Remote connections.
