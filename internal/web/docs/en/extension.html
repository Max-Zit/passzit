Browser extension

The PassZit extension fills your logins into websites, offers to save new ones and makes passwords — in Chrome, Edge, Opera, Brave, Vivaldi and Firefox. It brings its own code, so the server cannot change what runs in your browser.

Installing

Download the extension from Browser extensions in the menu of the web vault: the server packs it for its own version and shows the steps for your browser.

Once PassZit is in the store of your browser (Chrome Web Store, Microsoft Edge Add-ons, Firefox Add-ons), the same page shows Install in one click with the store of the browser you use first: install it there and the store keeps it up to date. The packages of the server stay under Install by hand.

  • Chrome, Edge, Opera, Brave, Vivaldi: the Chromium package passzit-extension-chromium-VERSION.zip. Until it is in the stores: unzip it, open chrome://extensions (edge://extensions, opera://extensions …), switch on Developer mode and choose Load unpacked.
  • Firefox: the Firefox package passzit-extension-firefox-VERSION.zip (Firefox 128 or newer). Firefox installs only signed add-ons permanently; until the add-on is published, load it for testing in about:debugging → This Firefox → Load Temporary Add-on.

Signing in

  1. Click the PassZit icon, enter only the address of your server (for example https://vault.example.com) and click Connect with the web vault. The browser asks once whether PassZit may talk to that server — allow it.
  2. The web vault of the server opens. Sign in there as usual if you are not signed in yet (and unlock it).
  3. The vault asks Connect the PassZit extension in this browser …? — click Connect. The extension is signed in and unlocked; no password or code is typed in the extension.

Instead you can open Sign in with e-mail and master password instead in the extension and sign in there with the master password and the code of your authenticator app.

The extension appears under My account → Active sessions with the name of the browser; you can sign it out there. It stays signed in for 30 days (set by the administrator) and is signed out earlier when it is not used for 14 days.

The server needs a certificate the browser trusts. With the self-signed certificate of a fresh server the extension cannot connect: the administrator sets one under Settings → Certificate (your own certificate or Let's Encrypt). For a test server you can instead trust its certificate on your computer.

Filling logins

  • Open the sign-in page, click the PassZit icon: This site lists the logins for the website. Fill puts user name and password into the page.
  • In the menu (≡) switch on Show on the PassZit icon how many logins a website has: when you open a website with saved logins, the icon shows their number, so you see at once that PassZit knows the site. The browser asks once for access to all websites.
  • Keyboard: Ctrl+Shift+L fills the login directly when there is exactly one for the site, otherwise it opens the list.
  • The copy buttons copy the user name or the password; copied passwords are cleared from the clipboard again.

PassZit offers a login only on its own website: shop.example.co.uk gets the logins of example.co.uk, but a login for one github.io page is never offered on another, and a login saved for HTTPS is not offered on plain HTTP. It fills only visible fields of the top page, never into frames of other sites, and checks again right before filling that the page has not changed.

Offering to save

In the menu (≡) switch on Offer to save new and changed logins. The browser then asks for access to all websites — needed to notice when you sign in or change a password. When you do, the PassZit icon shows a number; open it and choose Save or Update. PassZit never shows anything inside the web page itself, so a page cannot imitate or click the offer.

Locking

One unlock: the extension and the web vault of the same server share the unlocked state — unlock one of them and the other opens too (when you open the web vault or the extension), lock one and both lock. Each side checks that the keys belong to the same account. Both stay open until you lock or close the browser, unless you chose a lock time under My account. The keys are kept in the browser's memory, never on disk.

When the extension is locked, Unlock in the web vault (Windows Hello) opens the web vault; unlock it there with Windows Hello (see My account) and the extension opens too.

One-time codes

Logins with an authenticator key get a clock button that copies the current one-time code. After Fill such a login, PassZit also puts the code on the clipboard, because most sign-ins ask for it on the next page. On the page that asks for the code, Fill (or Ctrl+Shift+L) puts the code straight into the field — also into one box per digit. The code is cleared from the clipboard like a password.

When you switch on two-factor sign-in at a website and it shows a QR code, open PassZit and click Read an authenticator QR code on this page. The browser gives PassZit a picture of the visible tab (only after this click); PassZit reads the code in your browser and saves the key in a login of the site you choose, or in a new login. Then enter the code PassZit shows to finish the setup at the website.

Generator and search

Generator makes passwords and passphrases like the one in the web vault; Search finds any item of your vault to copy its user name or password.

Remote connections

With the MaxZit Launcher the extension also opens RDP, SSH, WinBox and other connections of your logins — see Remote connections.
