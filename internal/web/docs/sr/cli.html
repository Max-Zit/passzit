Komandna linija

Komanda passzit čita prijave u skriptama i na serverima. Kao i pregledač, sve dešifruje na svom računaru: server vidi samo token uređaja i šifrovane podatke. Svako izdanje je sadrži za Linux (amd64, arm64) i Windows.

Prijava

passzit login --server https://vault.example.com --email ja@example.com

Traži glavnu lozinku i kod iz aplikacije za autentifikaciju, a zatim se pojavljuje u Moj nalog → Aktivne sesije kao „PassZit CLI on računar“, gde je možete odjaviti. Token uređaja se čuva u vašem folderu podešavanja (~/.config/passzit/cli.json, na Windows-u %APPDATA%\passzit\cli.json), čitljiv samo vama. Prihvataju se samo HTTPS serveri.

Otključavanje za sesiju

export PASSZIT_SESSION="$(passzit unlock --raw)"     # Linux, macOS
$env:PASSZIT_SESSION = (passzit unlock --raw)        # Windows PowerShell

Ključ sesije u PASSZIT_SESSION otvara kopiju ključa naloga koju je unlock sačuvao zapečaćenu; bez promenljive ta kopija ne vredi ništa. passzit lock briše kopiju. Bez PASSZIT_SESSION svaka komanda traži glavnu lozinku.

Čitanje prijava

passzit list github                 # stavke čiji naziv, korisničko ime ili adresa sadrže „github“
passzit get password "GitHub"       # samo lozinka, za skripte
passzit get username GitHub
passzit get totp GitHub             # trenutni jednokratni kod
passzit get notes "Ruter kancelarija"
passzit get item 3f2a9c1e           # cela stavka kao JSON (id ili njegovih prvih 8 znakova)
passzit generate --length 24

Naziv koji odgovara više stavki se odbija uz spisak njihovih id-jeva; tada koristite id. Komandna linija čita vaš lični trezor i deljene trezore čiji ste član; ne menja stavke.

Stanje i odjava

passzit status
passzit logout
