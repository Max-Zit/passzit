Instalacija servera

PassZit je jedan program, passzit-server, sa PostgreSQL bazom. Instalirajte ga jednom komandom, iz Linux paketa ili kao gotov appliance image.

Zahtevi

  • Linux: Debian 12+, Ubuntu 22.04+, AlmaLinux ili Rocky Linux 9+ — x86_64 ili arm64; 1 CPU, 1 GB RAM-a, nekoliko GB diska.
  • PostgreSQL 14 ili noviji (instalaciona skripta ga podešava na istom serveru).
  • Za ekstenzije pregledača i telefone: ime i sertifikat kome pregledači veruju — ekstenzije odbijaju samopotpisane sertifikate. Postavite PassZit iza svog reverse proxy-ja sa sertifikatom ili zamenite fajlove u /var/lib/passzit/tls.

Instalacija jednom komandom

Kao root na novom serveru:

curl -fsSL https://github.com/Max-Zit/passzit/releases/latest/download/install.sh | sudo sh

Skripta instalira PostgreSQL, preuzima najnovije izdanje, proverava njegov potpis (instaliraju se samo izdanja potpisana PassZit ključem za izdanja), pravi bazu sa nasumičnom lozinkom, pokreće servis i ispisuje adresu i token za podešavanje. Otvorite https://SERVER:8443, unesite token i napravite prvog administratora sa prijavom u dva koraka.

Opcije (sh -s -- OPCIJE kada se prosleđuje kroz cev): --version X određeno izdanje, --db URL postojeća PostgreSQL baza, --no-auto-updates ne uključuje automatska bezbednosna ažuriranja operativnog sistema, --source URL mirror. Ponovno pokretanje skripte ažurira PassZit i čuva sve podatke.

Linux paketi

Svako izdanje ima .deb i .rpm pakete za amd64 i arm64. Oni instaliraju program, ojačan systemd servis passzit-server (sopstveni korisnik, sistem samo za čitanje, bez dodatnih privilegija), root helper za ažuriranja i /etc/passzit/server.env. Tamo podesite PASSZIT_DB i pokrenite servis:

sudo apt install ./passzit-server_VERZIJA_amd64.deb
sudo nano /etc/passzit/server.env      # PASSZIT_DB=postgres://…
sudo systemctl start passzit-server

Appliance

Appliance image-i (OVA za VMware, QCOW2 za Proxmox/KVM, VHDX za Hyper-V, ISO za bilo koju mašinu) sadrže Debian, PostgreSQL i PassZit, spremne za pokretanje. Prijavite se na konzoli VM-a kao pzadmin (prva lozinka passzit, menja se pri prvoj prijavi): meni podešava mrežu, ime servera i vremensku zonu, prikazuje token za podešavanje i vraća rezervne kopije. Otvoreni su samo portovi 22 (SSH) i 8443.

Ažuriranja

Podešavanja → Ažuriranja i server pokazuje verziju koja radi i najnoviju verziju. Instaliraj predaje ažuriranje root helperu: on ponovo proverava potpis, pravi rezervnu kopiju baze i programa, instalira paket i proverava da li se server vratio — ako nije, sam vraća staru verziju i bazu. Tu se može uključiti i automatska instalacija u izabranom satu.

Kanal ažuriranja je Stabilni (najnovije izdanje) ili Testni, koji nudi i kandidate za izdanje pre nego što postanu stabilni — koristite ga na test serveru. Mirror ili lokalni folder podešava se sa PASSZIT_UPDATE_SOURCE u server.env; i njegova izdanja moraju imati potpis.

Rezervna kopija i vraćanje

Podešavanja → Rezervna kopija konzole svaki dan (i na zahtev) pravi rezervnu kopiju u /var/lib/passzit/backups: bazu sa svim trezorima, tajni ključ servera i sertifikat konzole. Rezervna kopija je uvek šifrovana lozinkom koju sami postavite (AES-256) — čuvajte je na drugom mestu. Svaka rezervna kopija može se i kopirati u SFTP folder na drugom serveru; prvi test veze pokazuje otisak ključa servera kome treba verovati.

Za vraćanje zaustavite servis i pokrenite vraćanje na novom ili popravljenom serveru (appliance meni to radi umesto vas):

sudo systemctl stop passzit-server
sudo -u passzit sh -c 'set -a; . /etc/passzit/server.env; passzit-server -data-dir /var/lib/passzit -restore /putanja/passzit-backup-….pzb -restore-passphrase-file /putanja/lozinka.txt'
sudo systemctl start passzit-server

Vraćanje zamenjuje celu bazu u jednom koraku — ako bilo šta ne uspe, ništa se ne menja. Novija verzija PassZit-a migrira vraćenu bazu pri pokretanju.

Web trezor kao aplikacija

Pregledači nude da instalirate web trezor (Chrome, Edge: ikona za instalaciju u adresnoj traci; telefoni: Dodaj na početni ekran). Tada se otvara u sopstvenom prozoru. Ništa iz trezora se ne čuva za rad bez mreže: bez servera vidite kratku stranicu „offline“.

Pravljenje iz izvornog koda

git clone https://github.com/Max-Zit/passzit
cd passzit
go run ./tools/buildwasm          # Argon2id za pregledač
go build -o passzit-server ./cmd/passzit-server
export PASSZIT_DB=postgres://passzit:TAJNA@localhost/passzit
./passzit-server --data-dir /var/lib/passzit --listen :8443

Pri prvom pokretanju server u direktorijumu podataka pravi svoj tajni ključ (secret.key), sertifikat i token za podešavanje (setup-token.txt).

Bez rezervne kopije konzole sami čuvajte kopiju baze i fajla secret.key. Trezori su šifrovani ključevima korisnika, ali sopstvene tajne servera (drugi faktori, ključevi sesija) zahtevaju secret.key.

Opcije komandne linije

OpcijaZnačenje
--data-dirsertifikati, tajni ključ, rezervne kopije, logovi (podrazumevano /var/lib/passzit)
--dbPostgreSQL URL (ili PASSZIT_DB)
--listenadresa i port, zamenjuje sačuvano podešavanje
--restore FAJLvraća rezervnu kopiju konzole i izlazi (servis zaustavljen); lozinka u PASSZIT_BACKUP_PASSPHRASE ili --restore-passphrase-file
--reset-allowlistponovo dozvoljava privatne mreže i izlazi
--unblock-iposlobađa blokiranu adresu (ili all) i izlazi
--versionispisuje verziju i izlazi
--dev-embedded-dbprivatni PostgreSQL u direktorijumu podataka — samo za testove i demo
--dev-no-2faprijava bez drugog faktora — samo test i demo serveri, zahteva --dev-embedded-db; svaka stranica prikazuje upozorenje
